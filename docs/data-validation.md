## Numerical and methodological limits

Original floating-point extrema retained: {'minimum_Pop_Beyond_800': -2.2737367544323206e-12, 'maximum_Pct_Access_800': 100.00000000000013}. Tiny negative values/percentages above 100 are numerical noise; UI presentation may clamp only within documented tolerance. No source numbers were edited.

Population layer IDs and populations match the accessibility layer. Priority membership exactly matches coverage <50% and estimated beyond-800 m population ≥500; its attributes match the parent layer. The script fails for missing CRS/IDs, duplicate IDs, missing/empty geometry, unrepaired geometry, invalid exports, altered attributes or unexpected extent. Geometry fixes use make_valid only when necessary and record each affected ID and area.

GeoPackage geometry is transformed for display, not reanalysed. Six-decimal rounding is attempted, with increased precision when required to preserve valid polygons. The maximum Hausdorff change is measured with both geometries in EPSG:26917, in metres; exports exceeding 0.2 metres fail. Municipal boundaries, when included, are contemporary context and do not replace historical municipality assignments.

## Reproduce

```powershell
uv venv --python 3.12 .venv
uv pip install --python .venv/Scripts/python.exe -r requirements-data.txt
.venv/Scripts/python.exe scripts/prepare_data.py --source-dir ../../work/source-repository --municipalities data/reference/municipalities.geojson --municipalities-source data/reference/municipalities-source.json
```

Omit both municipality arguments for a DA-only run. Municipal provenance is required when including that layer. The source checkout must be obtained separately; raw data is not overwritten. Source checksums and software versions are recorded in the manifest.
