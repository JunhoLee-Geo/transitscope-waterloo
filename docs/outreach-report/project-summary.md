# Project summary

TransitScope extends Junho Lee's Python Waterloo transit accessibility analysis into a static JavaScript Web GIS. MapLibre renders GeoJSON; Python and GeoPandas prepare and validate it. The application supports public exploration rather than live journey planning.

Validated historical results: 587,165 residents, 766 DAs, approximately 437,870 residents within 400 m, 506,721 within 800 m and 80,444 beyond 800 m; 52 priority DAs. These are area-weighted estimates using 2021 Census population and saved September 9, 2026 analysis. They are not counts of individual residents with walkable transit access.

A separate November 24, 2026 GTFS snapshot supplies 2,289 boarding stops and 167 route-shape features. Its scheduled service does not update historical population estimates.

This evidence package describes automated implementation and verification. It does not attest to the student's independent coding, tutorial completion, or personal learning. See [validation](validation-summary.md), [QA](final-qa-report.md), and [learning activities](learning-summary.md).
