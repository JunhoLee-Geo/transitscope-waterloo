# References used in development

These entries describe sources consulted during automated development. They do not assert personal reading by the student. Undated documentation uses n.d.; retrieval date is November 25, 2026. Review citation formatting against course requirements.

- Grand River Transit. (n.d.). *Open data*. https://www.grt.ca/about-grt/open-data/ (GTFS feeds and reuse terms.)
- Region of Waterloo. (n.d.). *Open data*. https://regionofwaterloo-018-ca.govstack.com/government-and-council/transparency-and-accountability/open-data/ (Open Data Licence; heading v.2.0 and a later v.1.0 reference are inconsistent.)
- Statistics Canada. (2025, July 10). *Statistics Canada Open Licence*. https://www.statcan.gc.ca/en/terms-conditions/open-licence (Page modification date; attribution and adapted-data notice.)
- MapLibre. (n.d.). *MapLibre GL JS*. https://maplibre.org/maplibre-gl-js/docs/ (Map, sources, layers, feature state and events.)
- Butler, H., Daly, M., Doyle, A., Gillies, S., Hagen, S., & Schaub, T. (2016, August). *The GeoJSON format* (RFC 7946). Internet Engineering Task Force. https://www.rfc-editor.org/rfc/rfc7946 (Geometry, properties and coordinates.)
- MobilityData. (n.d.). *GTFS Schedule Reference*. https://gtfs.org/documentation/schedule/reference/ (Calendars, stop times, shapes and pickup rules.)
- GeoPandas developers. (n.d.). *Projections*. https://geopandas.org/en/stable/docs/user_guide/projections.html (CRS assignment versus transformation.)
- Vite. (n.d.). *Deploying a static site*. https://vite.dev/guide/static-deploy.html (Repository base path and Pages workflow.)
- GitHub. (n.d.). *Configuring a publishing source for your GitHub Pages site*. https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site (Actions publishing source.)
- OpenStreetMap Foundation. (n.d.). *Tile usage policy*. https://operations.osmfoundation.org/policies/tiles/ (Attribution, caching and prohibited bulk use.)
- OpenStreetMap contributors. (n.d.). *Copyright and license*. https://www.openstreetmap.org/copyright (ODbL and attribution.)
- Lee, J. (n.d.). *Waterloo transit accessibility* [Source code and analytical outputs]. GitHub. https://github.com/JunhoLee-Geo/Waterloo-transit-accessibility (Inspected commit recorded in data-sources.md.)
