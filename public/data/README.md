# Validated browser data

Generated by scripts/prepare_data.py. Original analysis commit: 966a88ccde44994fa2e60060c2b7c332228528ed. See manifest.json for input hashes, source fields, coordinate precision, measured geometry displacement, and provenance; see ../../docs/data-validation.md for a readable report.

- da-population.geojson: 766 baseline DA polygons with Census population.
- da-accessibility.geojson: 766 DAs with original area-weighted proximity estimates and municipality assignments.
- priority-underserved.geojson: 52 DAs in the verified original priority subset.
- municipalities.geojson: seven official polygons retrieved separately as current context; not confirmed as the original boundary snapshot.
- municipality-summary.json: original CSV values, including its rounding and historical stop counts; stop counts were not independently revalidated.

All geometry uses EPSG:4326 longitude/latitude. Original attribute numbers and names are preserved; DAUID is a string. No fabricated features or reconstructed GTFS geometries are included. The browser loads only the accessibility, priority and municipality layers. The baseline export is available for inspection/reuse.

Source data licensing and attribution must be reviewed before public redistribution. These files are local project deliverables; nothing has been deployed.

## Separate Phase 3 network
`transit/` contains current official GTFS-derived stops, routes and dissolved buffers, with its own manifest and service date. Do not join these buffers to historical population accessibility figures as if they reproduce that analysis. See ../../scripts/GTFS.md and ../../docs/gtfs-validation.md.
